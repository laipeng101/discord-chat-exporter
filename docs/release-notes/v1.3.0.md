# v1.3.0 --- Portable compressed archive, avatars, emoji, and efficient scrolling

## 中文

-   采集并显示真实作者头像，失败时回退到首字母头像。
-   保留 Unicode 与 Discord
    自定义表情，并结构化保存反应数量和当前账号点选状态。
-   作者、头像、表情、媒体改为字典复用，消息只保存索引。
-   HTML 内嵌数据库使用浏览器原生 gzip 压缩，同时保持单文件便携性。
-   当前视窗晚于目标范围时直接向上边滚边采集，到达开始边界后结束，不再重复回扫。
-   1,796 条消息样本的主要消息/媒体/反应数据从约 1.98 MB 降至约 181 KB。

## English

-   Added real author avatars with initial-based fallback.
-   Preserved Unicode/custom emoji and structured reaction
    count/selection state.
-   Normalized authors, avatars, emoji, and media into reusable
    dictionaries.
-   Compressed the embedded portable HTML archive database with native
    gzip.
-   Removed redundant top-then-down rescanning when collecting an older
    date range.
-   In the 1,796-message regression sample, core archive data dropped
    from about 1.98 MB to about 181 KB.
