# v1.5.1 — Exclude the Discord channel welcome card

## 中文

- 修复频道欢迎卡片被导出为空白消息的问题。采集仍用欢迎卡片识别频道历史起点，并保留真实的系统消息及 ID 与子区相同的首帖。

## English

- Exclude the channel welcome card from exports while still using it to detect the start of channel history. Real system messages and thread starters whose IDs match their thread IDs remain exportable.
