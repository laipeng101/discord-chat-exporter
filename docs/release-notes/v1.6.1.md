# v1.6.1 — Faster exports and fewer background scans

- Skip scans for unrelated page changes while still tracking edits, reaction updates, and attachment changes in the active message list.
- Count messages by channel and date range without sorting or copying the full history. Reuse avatar and custom emoji URL lookups while generating HTML archives.
- Separate message reading, record storage, date traversal, export formats, and panel code. The installed userscript remains a single file.
- Includes the eight languages and clearer export prompts introduced in [v1.6.0](https://github.com/laipeng101/discord-chat-exporter/blob/v1.6.1/docs/release-notes/v1.6.0.md).

In alternating Chrome tests against the v1.6.0 source, exporting 41 loaded messages to HTML took 5.79 ms, down from 8.46 ms. Generating HTML for a 13,818-record fixture expanded from those messages took 116.1 ms, down from 386.9 ms. Both figures are median times through file generation.
