# v1.4.0 --- Stable emoji and reaction rendering

## 中文

-   普通 Unicode 表情直接保存为字符，不再引用易失效的 Discord 构建 SVG。
-   自定义表情只保留带 emoji ID 的稳定 CDN WebP 地址，并按 ID 去重。
-   动态/静态候选同时存在时优先保留动画版本。
-   自定义表情加载失败回退到 `:表情名:`，头像失败回退到作者首字母。
-   真实样本回归：645 条消息、76 条原始反应；清除 50 条错误远程
    URL，合并 3 条重复候选，得到 73 条正确反应记录。

## English

-   Store standard emoji as Unicode characters instead of unstable
    Discord build SVG assets.
-   Keep only stable CDN WebP URLs for custom emoji and deduplicate by
    emoji ID.
-   Prefer animated candidates when both animated and static variants
    are present.
-   Fall back to `:emoji_name:` and author initials when remote assets
    fail.
-   Regression sample: 645 messages and 76 raw reactions; removed 50
    invalid remote URLs and merged 3 duplicate candidates into 73
    correct reaction records.
