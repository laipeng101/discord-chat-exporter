# v1.4.2 — Native wording refinements

## 中文

-   繁体中文统一使用「擷取」表达采集/收集，避免「採集」与「擷取」混用。
-   日语 idle 改为「待機中」，stalled 改为更自然的「取得済みの履歴」。
-   韩语滚动速度选项统一为「빠른 속도 / 보통 속도 / 느린 속도」。
-   西班牙语、法语、德语、巴西葡语、俄语、阿拉伯语的 idle 文案统一为「已就绪 / 等待中 / 当前频道可继续采集」语义，不再暗示监控。
-   俄语 embeds 改为「Встроенный контент」，stalled 改为「Все полученные сообщения сохранены」。
-   同步更新繁中 Greasy Fork 附加说明按钮文案。

## English

-   Traditional Chinese now consistently uses 「擷取」 for collect/fetch.
-   Japanese idle now reads 「待機中」 and stalled uses the more natural 「取得済みの履歴」.
-   Korean scroll-speed options are unified as 「빠른 속도 / 보통 속도 / 느린 속도」.
-   Spanish, French, German, Brazilian Portuguese, Russian, and Arabic idle wording now means ready/waiting/ready-to-collect rather than monitoring.
-   Russian embeds now reads 「Встроенный контент」 and stalled reads 「Все полученные сообщения сохранены」.
-   Synced the Traditional Chinese Greasy Fork additional-info button label.
