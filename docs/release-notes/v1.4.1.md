# v1.4.1 — UI wording and localization

## 中文

-   统一按钮与状态文案：扫描当前可见消息、采集日期范围、清除已采集数据；避免「清空频道 / 监听 / 安全」等易误解表述。
-   将「安全 / 滚动等待」改为更准确的「较慢 / 滚动间隔」，并修正 idle 与 stalled 的语义。
-   修正 11 种语言的高风险文案，包括日语、韩语、西班牙语、法语、德语、巴西葡语、俄语、阿拉伯语与繁简中文。
-   导出 HTML/TXT 的贴纸、加载失败、归档标题标签改用当前语言，并移除硬编码英文「Stickers」。
-   元数据新增 @homepageURL 与 @supportURL；各语言 Additional info 加入 GitHub 仓库 / Issues 链接。
-   新增无依赖静态检查脚本 scripts/check-locales.mjs，校验 key、占位符、文件名与元数据 locale。
-   阿拉伯语面板与 HTML 归档继续使用 RTL 版式。

## English

-   Unified scan / fetch / clear / delay / idle / stalled wording so the UI no longer implies deleting the channel, network monitoring, or a safety guarantee.
-   Replaced “Safe” / “scroll waiting” with “Slower” / “scroll interval” and clarified idle and stalled semantics.
-   Fixed high-risk wording across all 11 locales, including Japanese, Korean, Spanish, French, German, Brazilian Portuguese, Russian, Arabic, and both Chinese variants.
-   HTML and TXT exports now localize stickers, archive-load failure, and the archive eyebrow; removed the hard-coded “Stickers”.
-   Added @homepageURL and @supportURL metadata and GitHub repo / issue links in every localized Greasy Fork additional-info page.
-   Added a dependency-free static check script scripts/check-locales.mjs for keys, placeholders, file names, and metadata locales.
-   Arabic panel and HTML archive retain RTL layout.
