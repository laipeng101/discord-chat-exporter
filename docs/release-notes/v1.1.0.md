# v1.1.0 --- Media export and bidirectional date seeking

## 中文

-   HTML 导出加入图片预览、视频播放器、音频播放器和普通文件链接。
-   新增结构化 `media` 字段，并在 CSV 中加入媒体列。
-   自动定位改为双向判断：目标范围较早时向上，较新时向下。
-   定位后使用重叠视窗采集，降低跳跃漏采风险。

## English

-   Added image previews, video/audio players, and normal file links to
    HTML exports.
-   Added a structured `media` field and a media column in CSV.
-   Added bidirectional date-range seeking based on the current
    viewport.
-   Continued collection with overlapping viewports to reduce missed
    messages.
