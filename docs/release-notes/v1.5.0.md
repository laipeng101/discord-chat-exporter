# v1.5.0 — Discord web message and history compatibility

## 中文

- 按当前频道的消息行采集。回复预览和转发快照不再被当成独立消息；附件等无正文消息仍可导出。
- 四种格式都保留转发正文。JSON 增加可选的 `forwarded` 字段，CSV 在末尾增加同名列。
- 按 Discord 的分组引用归属作者和头像，并兼容同一列表中两种反应控件。再次读到更新的附件签名链接时保留新链接。
- 识别 Discord 网页的频道起始卡片和分页占位；已读完当前批次时直接移到加载位置，停滞时会重新进入加载区。无法确认完整范围时保留已采集的消息，并跳过自动下载。

## English

- Collect rows from the channel in the browser address, including messages without a text body. Reply previews and forwarded snapshots no longer appear as separate messages.
- Preserve forwarded text in every format. JSON adds an optional `forwarded` field; CSV adds a final column of the same name.
- Use Discord's group references for authors and avatars, support both reaction layouts, and retain a newer attachment URL when Discord refreshes its signature.
- Recognize the Discord web channel start and pagination placeholders. Move to the loading area after reading the current batch, and re-enter it if loading stalls. If coverage cannot be verified, keep the collected messages and skip automatic download.
