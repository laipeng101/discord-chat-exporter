# Discord 聊天导出器

从 Discord 网页版导出当前频道中你有权限查看的消息。脚本在浏览器内处理聊天记录，不会上传聊天内容。

## 主要功能

-   选好开始和结束日期后，脚本会自动滚动消息列表。若所选日期内可能还有遗漏，仍可导出已采集的消息。
-   支持 TXT、JSON、CSV 和可直接阅读的单文件 HTML。
-   保留可读取的正文、作者、头像、回复、转发、链接预览、附件、贴纸和表情回应。
-   HTML 按本地日期整理聊天记录，可以搜索消息或发件人，也可预览仍能访问的图片、视频和音频。
-   面板和 HTML 聊天记录提供 19 种语言及地区版本。可跟随浏览器语言，也可手动选择。

## 使用

打开 Discord 网页版目标文字频道，选择日期范围和导出格式，点击
**按日期采集**。采集期间不要滚动消息列表，也不要切换频道。按
**Alt/Option + Shift + D** 可显示/隐藏面板。

日期按浏览器本地时区计算，结束日期包含当天全部消息。

## 隐私与限制

脚本只能读取当前登录账号已经由页面渲染出来的消息，不能绕过权限、恢复已删除消息，也不能直接读取
Discord 尚未加载的历史。HTML 中的媒体保留远程
URL，因此链接未来可能过期、被删除或需要权限。

请只导出你有权处理的聊天内容，并遵守服务器规则、适用法律和参与者隐私。
