# ส่งออกแชต Discord

บันทึกข้อความที่คุณดูได้ในช่อง Discord ที่เปิดอยู่เป็นไฟล์ TXT, JSON, CSV หรือ HTML ในไฟล์ HTML คุณสามารถค้นหาข้อความหรือชื่อผู้ส่งได้

## วิธีใช้

เปิดบทสนทนาใน Discord บนเว็บ เลือกวันที่เริ่มต้น วันที่สิ้นสุด และรูปแบบไฟล์ แล้วคลิก **รวบรวมข้อความตามวันที่** อย่าเลื่อนรายการข้อความหรือเปลี่ยนช่องระหว่างที่สคริปต์กำลังรวบรวมข้อความ เมื่อเสร็จแล้วให้คัดลอกหรือดาวน์โหลดผลลัพธ์ กด **Alt/Option + Shift + D** เพื่อแสดงหรือซ่อนแผงควบคุม

วันที่อิงตามเขตเวลาท้องถิ่นของคุณและรวมข้อความตลอดวันสิ้นสุด

## ความเป็นส่วนตัวและข้อจำกัด

ข้อความจะประมวลผลในเบราว์เซอร์และไม่ถูกอัปโหลด สคริปต์อ่านได้เฉพาะข้อความที่ Discord โหลดให้คุณ และกู้คืนข้อความที่ถูกลบไม่ได้ ไฟล์ HTML ยังโหลดสื่อจากลิงก์เดิม ซึ่งอาจหมดอายุหรือต้องมีสิทธิ์เข้าถึง
