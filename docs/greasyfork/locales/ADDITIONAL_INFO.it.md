# Esporta le chat di Discord

Salva i messaggi che puoi vedere nel canale Discord aperto in formato TXT, JSON, CSV o HTML. Nel file HTML puoi cercare messaggi e nomi dei mittenti.

## Come si usa

Apri la conversazione su Discord nel browser. Scegli la data di inizio, la data di fine e il formato, poi fai clic su **Raccogli i messaggi per data**. Non scorrere la lista e non cambiare canale mentre lo script raccoglie i messaggi. Al termine, copia o scarica il risultato. Premi **Alt/Option + Shift + D** per mostrare o nascondere il pannello.

Le date seguono il fuso orario locale. È incluso anche tutto il giorno della data di fine.

## Privacy e limiti

I messaggi vengono elaborati nel browser e non sono caricati su altri server. Lo script legge solo i messaggi che Discord ha caricato per te e non può recuperare quelli eliminati. Il file HTML carica i contenuti multimediali dai collegamenti originali, che possono scadere o richiedere l’accesso.
