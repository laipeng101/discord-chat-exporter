# Exportador de chats de Discord

Guarda los mensajes que puedes ver en el canal de Discord abierto. Puedes exportarlos como TXT, JSON, CSV o HTML. En el archivo HTML puedes buscar mensajes y nombres de usuarios.

## Cómo usarlo

Abre la conversación en Discord web. Elige la fecha de inicio, la fecha de fin y el formato, y haz clic en **Recopilar mensajes por fecha**. No desplaces la lista ni cambies de canal hasta que termine la recopilación. Después, copia o descarga el resultado. Usa **Alt/Option + Shift + D** para mostrar u ocultar el panel.

Las fechas se interpretan según tu zona horaria local. Se incluye todo el día de la fecha de fin.

## Privacidad y límites

Los mensajes se procesan en tu navegador y no se suben a ningún servidor. El script solo lee los mensajes que Discord cargó para ti y no puede recuperar mensajes eliminados. El archivo HTML carga el contenido multimedia desde sus enlaces originales, que pueden caducar o requerir acceso.
