# Ekspor Chat Discord

Simpan pesan yang dapat Anda lihat di kanal Discord yang sedang dibuka. Pilih TXT, JSON, CSV, atau HTML. Di file HTML, Anda bisa mencari pesan atau nama pengirim.

## Cara menggunakan

Buka percakapan di Discord versi web. Pilih tanggal mulai, tanggal akhir, dan format file, lalu klik **Kumpulkan pesan berdasarkan tanggal**. Jangan menggulir atau pindah kanal selama pengumpulan. Setelah selesai, salin atau unduh hasilnya. Tekan **Alt/Option + Shift + D** untuk menampilkan atau menyembunyikan panel.

Tanggal mengikuti zona waktu setempat. Seluruh hari pada tanggal akhir ikut disertakan.

## Privasi dan batasan

Pesan diproses di browser dan tidak diunggah. Skrip hanya membaca pesan yang telah dimuat Discord untuk Anda dan tidak dapat memulihkan pesan yang dihapus. File HTML tetap memuat media dari alamat aslinya. Tautan itu bisa kedaluwarsa atau memerlukan akses.
