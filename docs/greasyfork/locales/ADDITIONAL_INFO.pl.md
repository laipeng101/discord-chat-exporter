# Eksport czatu Discord

Zapisz wiadomości, do których masz dostęp w otwartym kanale Discorda, jako plik TXT, JSON, CSV lub HTML. W pliku HTML możesz wyszukiwać wiadomości lub nadawców.

## Jak używać

Otwórz rozmowę w przeglądarkowej wersji Discorda. Wybierz datę początkową, końcową i format pliku, a następnie kliknij **Zbierz wiadomości z wybranych dni**. Podczas zbierania nie przewijaj listy i nie zmieniaj kanału. Po zakończeniu skopiuj lub pobierz wynik. Skrót **Alt/Option + Shift + D** pokazuje lub ukrywa panel.

Daty są podawane w lokalnej strefie czasowej. Uwzględniany jest cały ostatni dzień.

## Prywatność i ograniczenia

Wiadomości są przetwarzane w przeglądarce i nigdzie nie są wysyłane. Skrypt czyta tylko wiadomości, które Discord załadował na Twoim koncie, i nie odzyskuje usuniętych wiadomości. Plik HTML pobiera multimedia z ich oryginalnych adresów. Te linki mogą wygasnąć lub wymagać dostępu.
